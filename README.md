# Rota — acompanhamento de entregas

Protótipo responsivo em português para acompanhar entregas. O projeto é estático e não requer instalação de dependências.

## Executar

Abra `index.html` no navegador. Para a tela de acesso, use o formulário de demonstração; qualquer e-mail e senha válidos abrem a lista de entregas.

## O que está incluído

- Tela de acesso com atalhos para cadastro e recuperação de senha.
- Lista de entregas, status, endereço e visualização ilustrativa de rastreamento.
- Detalhes da entrega com mapa demonstrativo, linha do tempo e confirmação de recebimento.
- Acesso ao suporte e página de configurações.

Os pedidos, mapa e informações de conta são dados de demonstração. O protótipo não se conecta a serviços de autenticação, mapas ou rastreamento em tempo real.
